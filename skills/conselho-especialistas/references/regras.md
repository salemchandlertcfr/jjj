# Regras e racionalizações

Base: S11 §7; estas regras preservam independência, lastro e decisão humana.

| Regra | Por quê e como conferir |
| --- | --- |
| Rodada 1 cega e independente | Influência prévia reduz informação independente; audite briefs, ordem e acesso real |
| Critérios e `refuta_se` prévios | Evita avaliação sob medida; vínculo auditável e hash, sem alegar prova automática de tempo |
| Sem soma, média ou vencedor | Uma objeção decisiva não é compensada por sinais de outros critérios |
| Mudar só com evidência nova | Evita conformismo; relacione cada mudança ao elemento novo |
| Concordância não verifica | Todos podem repetir uma premissa falsa; confira fontes e raciocínio |
| Modelos sem identidade nos briefs | Evita influência de marca e família; mapa fica privado |
| Mesmo modelo de juiz | Mantém o nível escolhido pelo usuário; diversidade vem do método e das fontes |
| Quem gerou não julga | Separe sessões produtoras de membros, crítico e relator |
| Ordem sorteada por membro | Mitiga viés de posição; preserve semente no painel privado |
| Síntese não recomenda | Expõe resistências e lacunas; escolha permanece humana |
| Claude primeiro, registrado | É a linha de base de S11; outras famílias só em experimento futuro autorizado |
| Membro usa brief e web autorizada | Sem dossiê/workspace; ferramenta disponível também pode vazar e exige auditoria |

| Racionalização | Resposta operacional |
| --- | --- |
| “Todos concordaram; não precisa pesquisar.” | Concordância não é verificação. Pesquise para derrubar e confira o lastro |
| “Só um discorda; é ruído.” | Preserve o argumento minoritário. A maioria pode estar errada |
| “Somo os sinais para facilitar.” | Mantenha os sinais por membro; não crie total nem ranking |
| “Falta critério; crio um razoável.” | Devolva o brief. Não crie critério depois para ajustar às opções |
| “O modelo caiu; uso qualquer outro.” | Só substituição explicitamente autorizada de mesmo nível; registre ou espere |
| “Faço troca em tudo por garantia.” | Exija divergência relevante e dose permissiva; uma troca no máximo |
| “O usuário prefere H2; aviso o conselho.” | Preferência não entra no brief |
| “Uma recomendação torna a síntese útil.” | Mostre condições e argumentos; recomendação desloca a decisão |
| “O script validou, então é verdade.” | Validação estrutural não confere ciência, neutralidade nem isolamento |
| “Um personagem pode fazer o crítico ausente.” | Não simule resultado. Preserve o bloqueio; dublês são só avaliação |
