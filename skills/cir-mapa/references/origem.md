# Origem, atribuição e maturidade

Este alpha concretiza o plano do usuário S15, “Plano detalhado — cir-mapa”,
recebido em cir-mapa.zip em 23/10/2026. O Markdown original é preservado com
SHA-256 no manifesto do repositório de desenvolvimento. S02 §7 define o papel;
S08 tema 2 define o ciclo; S09 passo 2 define o diagnóstico; S10 §9 define o cartão.
A criação usa a metodologia de S01 (skill-creator), não uma instalação global.

Os textos metodológicos destas referências são adaptados do plano recebido,
com exemplos fictícios claramente marcados. Os seis auxiliares e o núcleo Python
são implementação original desta revisão. Não foi copiado código ou texto das
skills externas citadas por S15 §2, portanto não se afirma uma licença ou uma
revisão upstream auditada para trechos inexistentes. Os links do plano são
atribuição de ideias e leitura futura, não dependências instaladas. A licença
do projeto não está definida; não declarar MIT/Apache para o pacote por inferência.

S15 detalha e altera S08/S02: árvore com outras causas em vez de cinco porquês
isolados; rivais em linhas sem matriz/contagem; busca e previsões prévias; 2.3
com triagem mais verificação e conselho completo; visão de fora cega; cotas,
sonda e guarda no banco; diagnósticos de contraste. A precedência neste trabalho
vem da seleção explícita do plano pelo usuário, não da data do arquivo.

O checkout usado não contém a condutora e só tem parte do conselho; a pesquisa
também não está implementada. Cartões não modificam um brief.py inexistente.
Os scripts são portáveis e testáveis fora do repositório; não provam eficácia,
independência real, conferência científica nem integração Notion/Claude.
As comparações, recall e aceite humano de S15 §13 continuam requisitos de
avaliação, não resultados deste alpha.
