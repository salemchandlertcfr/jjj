# Oito tipos de pergunta

S12, §5.3. Os códigos sem acentos são usados no JSON; os textos podem ter acentos.

| Código | Trabalho | Exemplo |
| --- | --- | --- |
| esclarecimento | Fixar sentido | Quando você diz insight, o que conta como um? |
| suposicao | Expor premissa | O que precisa ser verdade para isso funcionar como descreve? |
| evidencia | Ancorar em experiência ou fonte | Conte a última vez em que isso aconteceu? |
| alternativa | Examinar caminho já considerado ou documentado | Que outro caminho você já considerou? |
| consequencia | Examinar efeito | Se funcionar assim, o que muda para quem decide? |
| e se | Alterar condição | E se os dados chegarem com atraso, como muda a decisão? |
| contraexemplo | Confrontar caso contrário documentado | A ficha relata um caso divergente; como se compara com o seu? |
| limite teorico | Examinar limite de princípio | Sua versão depende de medir o efeito para cada pessoa? |

Nas perguntas baseadas em ficha, acrescente força e situação do apoio. Os
exemplos são formas, não questionário fixo. A origem de alternativas precisa
estar identificada; não aproveite o tipo para gerar soluções.
