# Atalhos que prejudicam a entrevista

S12, §§7 e 13.

| Tentação | Conduta |
| --- | --- |
| Dar opções para poupar esforço | Peça descrição primeiro; opções direcionam reflexão. |
| Sugerir a resposta e pedir confirmação | Faça pergunta aberta. |
| Juntar perguntas | Uma ideia por vez; só logística independente vai em rodada. |
| Só mais uma pergunta | Identifique que decisão ela muda. |
| Perguntar o que pessoas em geral fazem | Encaminhe fato geral para pesquisa. |
| Concordar contra uma fonte para manter o clima | Preserve trecho, força e discordância. |
| Insistir até a pessoa aceitar a fonte | Pergunte uma vez; decisão é dela. |
| Tratar “faz sentido” como confirmação global | Vincule ao bloco efetivamente devolvido. |
| Dar exemplo de solução para destravar | Peça caso vivido, sem mecanismo sugerido. |
| Registrar a resposta “melhor escrita” | Preserve o texto original e marque leitura separada. |

Use o vocabulário da pessoa. Se pedir opinião, explique o papel do conselho
e das equipes e retome a investigação com um caso. Se responder várias ideias,
registre todas e aprofunde só a que muda mais a decisão.
